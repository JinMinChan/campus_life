# 한양의 하루

한양대학교 서울캠퍼스의 실제 지형·건물·보행로 위에서 한 학생의 대학생활을 지켜보는 작은 3D 게임입니다. 성향을 고르면 수업, 식사, 휴식과 친구 만나기를 스스로 선택합니다.

**플레이: https://jinminchan.github.io/campus_life/**

계정·서버·API 키 없이 GitHub Pages에서 실행됩니다. 학교와 관계없는 비공식 프로젝트입니다. 인물, 시간표와 사건은 가상입니다.

## 이번 버전

- 실제 건물 62개와 도로/보행로 256개, 캠퍼스의 언덕과 계단을 유지했습니다. 역사관 석조 포치, 백남학술정보관 원형 상부, 애지문, 노천극장, 사자상 주변을 절차적으로 표현했습니다.
- 가을 수목 620그루, 건물 입면·처마·기단·지붕 장식, 벤치·깃발·가로등·카페 테이블과 시간대에 따른 빛을 추가했습니다. 모든 표현은 직접 만든 기하 모델이며 참고 작품의 에셋을 복제하지 않았습니다.
- 학생은 걷기, 기다리기, 앉기, 읽기, 식사, 대화, 수면 자세를 바꿉니다. 높은 사선 조감도에서 전체를 보거나, 학생 가까이 따라갈 수 있습니다.
- 계획가는 일찍 수업에 가고 복습을 많이 합니다. 탐구가는 책과 산책을 선택하며, 사교가는 익숙한 친구의 식사·대화에 합류합니다. 욕구가 급하면 성향보다 식사와 휴식을 우선합니다.
- 실제로 같은 장소에서 시간을 함께 보낸 학생만 관계를 얻습니다. 함께한 식사와 공부, 처음 인사, 친구가 된 날이 저장됩니다. 반복된 점심은 다음날 만남으로, 지각 경험은 다음 수업의 빠른 출발로 이어집니다.
- 3일마다 오후 수업에 작은 시험이 있습니다. 공부와 함께한 노트 정리가 시험 준비와 결과에 영향을 줍니다.
- 숫자 패널을 줄이고 짧은 생각, 현재 행동, 최근 사건과 쌓인 기억을 중심으로 UI를 다시 만들었습니다.

## 조작

| 조작 | 기능 |
|---|---|
| 드래그 / 오른쪽 드래그 / 휠 | 회전 / 이동 / 확대·축소 |
| 학생 클릭 또는 학생들 목록 | 관찰할 학생 선택 |
| 인물 카드의 추적 아이콘 / F | 가까이 따라가기·추적 해제 |
| 내 학생 | 주인공 김하늘로 돌아가기 |
| 전체 보기 / H | 캠퍼스 조감도 |
| Q, E / +, − | 회전 / 확대·축소 |
| Space / 재생 버튼 | 정지·재생 |
| 1×, 3×, 12× | 시간 속도. 1×는 현실 1초에 게임 1분 |
| 사진 아이콘 / Esc | UI 없는 화면 / 돌아가기 |
| 자세히 / 쌓인 기억 보기 | 선택 이유·관계·시간표 / 오래 남은 사건 |
| 저장 / 안내의 저장 파일 | 브라우저 저장 / JSON 내보내기·불러오기 |

6초마다 자동 저장하며, 탭이 숨겨지거나 페이지를 닫으면 시간이 멈춥니다. 관계·경험·시간표·기억과 카메라·배속·정지 상태를 복원합니다. 기존 v1 저장은 새 경로망으로 옮깁니다.

브라우저/기기/주소별 저장 공간은 독립적입니다. 기존 로컬 플레이를 GitHub Pages로 옮기려면 로컬 게임 안내에서 저장 파일을 내려받고, 공개 게임 안내에서 불러오세요. 손상된 가져오기 파일은 현재 게임을 교체하지 않습니다.

## 로컬 실행과 빌드

```bash
python3 scripts/build.py
python3 run.py
```

http://127.0.0.1:4173 에서 정적 빌드가 열립니다. 다른 포트는 `python3 run.py --port 4174`로 지정합니다. 개발 중 원본 소스를 바로 보려면 다음을 사용합니다.

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

Python 3 표준 라이브러리만으로 빌드·실행합니다. Three.js와 지도도 로컬 자산이므로 CDN 의존이 없습니다. ES 모듈 때문에 `file://`로 더블클릭해 실행하는 방식은 지원하지 않습니다.

## GitHub Pages 배포

`main` push 시 `.github/workflows/pages.yml`이 정적 자산을 검사하고 `dist/`를 생성하여 GitHub Pages에 배포합니다. GitHub 저장소 Settings → Pages의 Source는 **GitHub Actions**입니다. 개인 컴퓨터나 로컬 서버를 켜 둘 필요가 없습니다.

`dist/`, 로컬 서버 PID/로그, 참고 이미지, 브라우저 임시 프로필은 버전 관리에서 제외합니다. `build-manifest.json`에는 배포된 각 자산의 SHA256이 기록됩니다.

## 검증

```bash
# 브라우저 시뮬레이션 및 실제 3D UI 검사 (서버가 실행된 상태)
python3 scripts/verify.py --url http://127.0.0.1:4173

# Node가 있는 환경에서 동일한 시뮬레이션 검사
node scripts/simulation_test.mjs
```

`tests.html`의 40개 검사는 72시간 경로·충돌·정체, 성향별 실제 행동 시간, 지각 후 출발 변화, 반복 식사·친구·공동 학습·시험 결과, 저장 및 복원 이후 같은 미래, v1 이동과 손상 파일 거절을 검사합니다. 3D UI 검사는 브라우저에서 조작, 실제 geometry 렌더링, 정지, 카메라·배속·저장과 UI 상태를 검사합니다.

`TEST_REPORT.md`와 `artifacts/*-results.json`에서 실제 수행 결과와 한계를 확인할 수 있습니다. `?qa=1&fresh=1`은 사용자 저장에 쓰지 않는 자체 검증 화면입니다. `?qa=1&fresh=1&view=close`는 검증 뒤 학생 근접 화면을, `&view=story`는 실제 시뮬레이션을 200분 진행한 장면을 보여 줍니다. `#runtime-diagnostics`에는 실제 프레임 속도와 렌더링 호출·오류·학생 상태를 기록합니다.

## 표현 범위

실제 OSM 배치·윤곽을 바탕으로 외관과 수목·높이 일부를 재해석한 그림 같은 캠퍼스입니다. 실측 건축 복원이나 정밀 내비게이션은 아닙니다. 출입구는 통행 가능한 보행로 쪽으로 근사합니다. 강의·독서·수면 같은 실내 활동도 출입구 부근의 작은 장면으로 표현하며, 건물 내부는 구현하지 않았습니다. 실시간 보행자 충돌 회피는 제한적입니다. 학기 전체 진급·전공별 커리큘럼·실제 캠퍼스 시간표는 다루지 않습니다.

## 파일 구조와 출처

- `src/world.js`: 지형·건축·수목·학생·카메라·빛
- `src/simulation.js`: 안전한 경로망·욕구·성향·시간표·관계·기억·저장
- `src/main.js`, `index.html`, `src/style.css`: 관찰 UI와 시간·저장 연결
- `src/qa.js`, `scripts/simulation_checks.mjs`, `tests.html`: 브라우저 검사
- `public/data/campus.json`: OpenStreetMap 파생 데이터
- `data/`: 원본 OSM XML 및 지형 두 타일
- `public/vendor/`: Three.js r170, OrbitControls 및 라이선스
