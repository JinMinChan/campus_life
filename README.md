# 한양의 하루

한양대학교 서울캠퍼스의 실제 지형·건물·보행로 위에서 한 학생의 대학생활을 지켜보는 작은 3D 게임입니다. 작은 바람 하나를 품은 학생이 스스로 살아가는 112일을 지켜봅니다. 공부와 성장, 친구와 첫사랑이 실제 일상에서 이어집니다.

**플레이: https://jinminchan.github.io/campus_life/**

계정·서버·API 키 없이 GitHub Pages에서 실행됩니다. 학교와 관계없는 비공식 프로젝트입니다. 인물, 시간표와 사건은 가상입니다.

## 작은 바람을 지켜보는 112일

처음에 하늘의 성향과 이번 학기의 작은 바람 하나를 고릅니다. 그 뒤에는 일정을 채우거나 매주 선택창에 답할 필요가 없습니다. 하늘이 성향·바람·학사 일정·컨디션을 따라 스스로 생활을 꾸리고, 다음 날과 다음 주로 이어갑니다.

- **지켜볼 이유:** 배움을 자신 있게 나누기, 오래 갈 친구 만들기, 누군가와 서로 마음을 알아가기, 내 생활을 꾸려 가기. 선택한 바람마다 실제 행동으로 이루어지는 작은 단계와 다음 한 걸음이 있습니다.
- **사건이 남는 관찰:** 수업과 공부, 함께 먹은 밥, 일한 시간, 충분한 신뢰를 바탕으로 한 고백과 데이트가 기록됩니다. 바람의 단계는 버튼을 누르거나 시간이 지났다는 이유만으로 달성되지 않습니다.
- **간섭은 선택 사항:** 마음이 쓰일 때 수첩에서 응원 한마디를 건넬 수 있습니다. 바로 수치를 지급하는 대신 다음 실제 활동에 작은 영향을 줍니다. 응원 없이도 학기는 끝까지 진행됩니다.
- **필요할 때 여는 수첩:** 작은 바람, 관계, 지나온 날들과 성적을 돌아봅니다. 수요일의 결정과 주간 결산이 자동 팝업으로 관찰을 끊지 않습니다. 16주 끝에서는 시간을 멈추고 기록을 다시 펼쳐볼 수 있습니다.

월요일부터 일요일까지 모든 날을 실제 시뮬레이션합니다. 하루로 일주일을 대신하지 않습니다. 평일 수업·주말의 자유시간·밤의 휴식이 이어지고, 일요일 저녁의 기록을 남긴 뒤 다음 월요일 아침으로 넘어갑니다. 중간고사·팀 과제·축제·기말고사가 생활과 성장에 영향을 줍니다. 과목과 학사 일정은 게임을 위한 가상 설정입니다.

실제 건물 62개, 도로·보행로 256개, 가을 수목 620그루의 캠퍼스와 걷기·기다리기·독서·식사·대화·휴식 자세를 유지했습니다. 계획가는 복습을, 탐구가는 산책과 발견을, 사교가는 익숙한 사람과의 시간을 더 자주 선택합니다.

## 조작

| 조작 | 기능 |
|---|---|
| 드래그 / 오른쪽 드래그 / 휠 | 회전 / 이동 / 확대·축소 |
| 학생 클릭 또는 학생들 목록 | 관찰할 학생 선택 |
| 인물 카드의 추적 아이콘 / F | 가까이 따라가기·추적 해제 |
| 내 학생 | 주인공 김하늘로 돌아가기 |
| 전체 보기 / H | 캠퍼스 조감도 |
| Q, E / +, − | 회전 / 확대·축소 |
| Space / 재생 버튼 | 정지·재생 |
| 1×, 3×, 12× | 시간 속도. 1×는 현실 1초에 게임 1분 |
| 관찰 수첩 | 작은 바람·관계·지나온 날들과 학기 결산 |
| 다음 장면 | 실제 생활을 45분 진행. 날짜를 대표 하루로 압축하지 않음 |
| 사진 아이콘 / Esc | UI 없는 화면 / 돌아가기 |
| 자세히 / 쌓인 기억 보기 | 선택 이유·관계·시간표 / 오래 남은 사건 |
| 저장 / 안내의 저장 파일 | 브라우저 저장 / JSON 내보내기·불러오기 |

6초마다 자동 저장하며, 탭이 숨겨지거나 페이지를 닫으면 시간이 멈춥니다. 자율 생활의 바람·달성한 장면·응원·성장·관계·경험·학기 기록과 카메라·배속·정지 상태를 복원합니다. 기존 v1/v2의 기억과 기존 v3 학기의 성적·관계·진행을 보존해 관찰 모드로 이어갑니다. 예전 v3 저장은 공간이 허용되면 이 브라우저의 별도 키에 한 번 더 보관합니다.

브라우저/기기/주소별 저장 공간은 독립적입니다. 기존 로컬 플레이를 GitHub Pages로 옮기려면 로컬 게임 안내에서 저장 파일을 내려받고, 공개 게임 안내에서 불러오세요. 손상된 가져오기 파일은 현재 게임을 교체하지 않습니다.

## 로컬 실행과 빌드

```bash
python3 scripts/build.py
python3 run.py
```

http://127.0.0.1:4173 에서 정적 빌드가 열립니다. 다른 포트는 `python3 run.py --port 4174`로 지정합니다. 개발 중 원본 소스를 바로 보려면 다음을 사용합니다.

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

Python 3 표준 라이브러리만으로 빌드·실행합니다. Three.js와 지도도 로컬 자산이므로 CDN 의존이 없습니다. ES 모듈 때문에 `file://`로 더블클릭해 실행하는 방식은 지원하지 않습니다.

## GitHub Pages 배포

`main` push 시 `.github/workflows/pages.yml`이 정적 자산을 검사하고 `dist/`를 생성하여 GitHub Pages에 배포합니다. GitHub 저장소 Settings → Pages의 Source는 **GitHub Actions**입니다. 개인 컴퓨터나 로컬 서버를 켜 둘 필요가 없습니다.

`dist/`, 로컬 서버 PID/로그, 참고 이미지, 브라우저 임시 프로필은 버전 관리에서 제외합니다. `build-manifest.json`에는 배포된 각 자산의 SHA256이 기록됩니다.

## 검증

```bash
# 브라우저 시뮬레이션 및 실제 3D UI 검사 (서버가 실행된 상태)
python3 scripts/verify.py --url http://127.0.0.1:4173

# Node가 있는 환경에서 동일한 시뮬레이션 검사
node scripts/simulation_test.mjs
node scripts/semester_test.mjs
node scripts/observation_test.mjs
```

`tests.html`은 안전한 경로망 검사와 전체 학기 회귀 검사를 같은 브라우저에서 실행합니다. 서로 다른 계획으로 16주를 완주하고, 모든 112일의 진행, 주말 수업 여부, 행동·성장·관계·성적, 진행 단계별 저장 연속성, 손상 파일 거절을 검증합니다. 관찰 모드 검사는 바람 하나만 고른 뒤 112일을 이어가며 실제 성취·자율 결정·저장 연속성을 확인합니다. 3D UI 검사는 실제 DOM 버튼으로 바람·선택적 응원·수첩·배속·정지·카메라·저장을 조작합니다.

`OBSERVATION_REPORT.md`는 최신 관찰 모드 검증을, `TEST_REPORT.md`는 앞선 학기 버전 검증을 기록합니다. 각 버전의 실제 수행 결과와 한계를 분리합니다. `?qa=1&fresh=1`은 사용자 저장에 쓰지 않는 자체 검증 화면입니다. `#runtime-diagnostics`에는 실제 프레임 속도와 렌더링 호출·오류·학생·학기 상태를 기록합니다.

## 표현 범위

실제 OSM 배치·윤곽을 바탕으로 외관과 수목·높이 일부를 재해석한 그림 같은 캠퍼스입니다. 실측 건축 복원이나 정밀 내비게이션은 아닙니다. 출입구는 통행 가능한 보행로 쪽으로 근사합니다. 강의·독서·수면 같은 실내 활동도 출입구 부근의 작은 장면으로 표현하며, 건물 내부는 구현하지 않았습니다. 실시간 보행자 충돌 회피는 제한적입니다. 이번 버전은 가상의 두 과목과 한 번의 가을학기입니다. 학기 이후의 실제 계절학기·다년 진급·전공별 커리큘럼·공식 캠퍼스 시간표는 구현 범위에 포함하지 않습니다.

## 파일 구조와 출처

- `src/world.js`: 지형·건축·수목·학생·카메라·빛
- `src/simulation.js`: 안전한 경로망·욕구·성향·시간표·관계·기억·저장
- `src/semester.js`: 112일의 생활·학사 일정·성장·관계·학기 결산
- `src/observation.js`: 작은 바람·자율 계획과 선택·실제 성취 기록·선택적인 응원
- `src/semester-ui.js`, `src/semester.css`: 바람 선택과 관찰 수첩
- `src/main.js`, `index.html`, `src/style.css`: 관찰 UI와 시간·저장 연결
- `src/qa.js`, `scripts/simulation_checks.mjs`, `scripts/semester_checks.mjs`, `tests.html`: 브라우저 검사
- `public/data/campus.json`: OpenStreetMap 파생 데이터
- `data/`: 원본 OSM XML 및 지형 두 타일
- `public/vendor/`: Three.js r170, OrbitControls 및 라이선스
